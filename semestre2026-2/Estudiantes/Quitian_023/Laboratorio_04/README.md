# LinReg Model

Paquete de Python que proporciona herramientas computacionales para ajustar modelos de regresión lineal simple utilizando el algoritmo de minimización por gradiente descendente.

## Estructura del Paquete
- `linreg_model/`: Módulo principal con la lógica matemática y visualización.
- `ejemplo.py`: Script con un caso de uso aplicado a los datos del laboratorio.
- `DOCUMENTACION.md`: Manual detallado de las funciones de la librería.

Se recomienda usar un entorno virtual. Para instalar la librería localmente, ubícate en el directorio raíz del paquete y ejecuta:
