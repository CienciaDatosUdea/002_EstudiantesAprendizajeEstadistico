# Hoja de campo

Mateo Caballero Serna, Lucian Valle Aguilar

Una fila por colector y por hora. Cada campo está para responder "¿cuántos mosquitos vamos a traer?" y para comprobar los supuestos del punto 1.

| Campo | Por qué |
|---|---|
| Localidad, casa y coordenadas | saber dónde y agrupar las capturas de una casa |
| Fecha y noche (1 a 4) | ver cuánto cambian las noches |
| Hora de inicio y fin | calcular el esfuerzo real y ver a qué hora pican más |
| Sitio (adentro / afuera) | comprobar $k_{intra}$ |
| Colector | ver si alguien captura más que otro |
| Número capturado, **anotando los 0** | distinguir "no se capturó" de "no se anotó" |
| Género o especie | comprobar $f_{Anoph}$ |
| Lluvia, viento y luna | explicar por qué unas noches dan más |
| Minutos de interrupción | esfuerzo real, no el planeado |
| Número de frasco | seguir la muestra hasta el laboratorio |
